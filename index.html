The idea

A Hindi instruction and its English original mean the same thing. While the model learns Hindi, we also ask it to predict how the original, frozen model understood the English version. We need translated instructions only, never English answers.

loss = Hindi language loss + λ · (1 − cosine( predicted meaning of Hindi, frozen English meaning ))

What we found

  • Hindi was learned: loss fell from 1.43 to about 1.14 for every method.
  • BhashaJEPA moved English internals less: about 13% lower layer drift (one seed).
  • It did not measurably reduce forgetting. LoRA left almost nothing to reduce, and under full fine-tuning it lost about as much English as plain fine-tuning.
  • Belebele stayed near chance at 1B, so it cannot show Hindi or Kannada gains.

Limits

  • One 1B model, mostly LoRA, 3,000 machine-translated Hindi examples.
  • Only B1 and J1 have 3 seeds. Everything else is one run.
  • Hindi from a 1B model is still weak and Kannada is unusable.
  • Safety after multilingual tuning was not tested.

Pre-registered hypotheses

We committed to these before running the experiments. Open each one for the evidence.

H1: retains English better than naive fine-tuning Not supported
LoRA shows no measurable forgetting. Under full fine-tuning J1 lost about as much English as naive fine-tuning (one seed).
H2: prediction beats plain alignment Inconclusive
J1 has 3 seeds but B4 has only 1, so the seed-range rule cannot be applied.
H3: frozen anchor beats a moving target Not run
J2 is implemented in the code but was not trained.
H4: drift explains forgetting Partial
J1 has lower drift (0.65 vs 0.75 for naive), but with so little behavioural forgetting the link cannot be tested at this scale.
H5: transfers to unseen Kannada Not observed
Kannada scores stay near chance.

Run it yourself

You need a GPU with enough memory, a Hugging Face account, and access to the Llama 3.2 licence. The scripts were written on Kaggle (Linux), so on Windows use WSL2.

git clone https://github.com/VishalBasapure/Hashcode
cd Hashcode
pip install transformers==4.55.2 peft==0.17.0 datasets accelerate matplotlib
hf download meta-llama/Llama-3.2-1B-Instruct --local-dir models/llama
python data/prepare.py --tokenizer models/llama --out data
python train/train.py --method J1 --seed 0 --model models/llama --smoke
bash run_all.sh
